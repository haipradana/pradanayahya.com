# Sentimen Analisis Vonis Tom Lembong

## Overview

Project ini menganalisis respons publik terhadap vonis Tom Lembong. Fokusnya adalah memetakan sentimen, emosi, kata kunci dominan, dan topik pembicaraan yang muncul di media sosial.

Analisis ini menggabungkan klasifikasi sentimen berbasis BERT dan topic modeling untuk memahami bagaimana opini publik terbentuk di sekitar isu politik dan hukum.

## Analysis Pipeline

- Data cleaning dan normalisasi teks.
- Klasifikasi sentimen menggunakan model berbasis BERT.
- Analisis emosi untuk menangkap nuansa respons publik.
- Topic modeling untuk menemukan tema pembicaraan utama.
- Visualisasi word cloud, distribusi sentimen, distribusi emosi, dan topic map.

## Outputs

Folder hasil di repository berisi:

- `sentiment.png`
- `emosi.png`
- `topics.png`
- `wc.png`
- `sudah-sentiment.csv`

## Tech Stack

- Python
- BERT sentiment classification
- BERTopic/topic modeling
- NLP preprocessing
- Data visualization
