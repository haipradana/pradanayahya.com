# Sentimen Analisis Abolisi Tom dan Hasto

## Overview

Project ini menganalisis respons publik terhadap keputusan Presiden Prabowo yang memberikan abolisi kepada Tom Lembong dan amnesti kepada Hasto. Analisis dilakukan pada percakapan media sosial untuk melihat sentimen, pola narasi, dan topik yang paling sering dibicarakan.

## Analysis Pipeline

- Mengumpulkan dan membersihkan data percakapan publik.
- Melakukan sentiment analysis untuk memetakan kecenderungan respons.
- Menggunakan topic modeling untuk menemukan cluster isu utama.
- Membuat visualisasi word cloud dan peta topik.
- Merangkum insight dari distribusi sentimen dan topik.

## Outputs

Folder hasil di repository berisi visualisasi:

- `topic.png`
- `topic2.png`
- `wc.png`

## Tech Stack

- Python
- NLP preprocessing
- Sentiment analysis
- BERTopic/topic modeling
- Data visualization
